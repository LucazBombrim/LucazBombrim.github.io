Rotina de prospecção

1. Filtre a rota

Comece pelos municípios mais próximos de Itaporanga e agrupe visitas por região. A distância exibida é em linha reta, não é tempo de viagem.

2. Simule a abordagem

Use os cadastros fictícios para explorar as informações e simular a organização de uma abordagem comercial.

3. Registre a conversa

Abra o contato, preencha etapa, responsável, próxima ação e observações. O registro fica salvo neste navegador.

4. Exporte sua base

Use o botão “Exportar acompanhamento” dentro do contato para guardar uma cópia JSON das suas atualizações. O arquivo de origem continua preservado.

Sobre a demonstração

Todos os cadastros são fictícios. As posições são ilustrativas e servem somente para demonstrar filtros, mapa e acompanhamento. A base comercial do projeto original não foi publicada.
