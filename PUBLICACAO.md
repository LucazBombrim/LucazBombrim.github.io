# Publicação no GitHub

Repositório: [LucazBombrim/LucazBombrim.github.io](https://github.com/LucazBombrim/LucazBombrim.github.io).

Endereço do portfólio: [lucazbombrim.github.io](https://lucazbombrim.github.io/).

## Site do portfólio

1. Coloque o `index.html` e as quatro pastas de demonstrações na raiz do repositório.
2. Mantenha a branch principal com o nome `main`.
3. Em **Settings → Pages → Build and deployment → Source**, use **Deploy from a branch**.
4. Selecione **main** e **/ (root)**. Novos envios para a branch geram a publicação.
5. O endereço padrão é `https://lucazbombrim.github.io/`. Não há domínio personalizado configurado.

Para uma exportação local equivalente, `npm run check` valida o portfólio e `npm run build` prepara o diretório `dist/`. Não há dependências npm para instalar. As demonstrações não incluem os arquivos de autenticação ou a base comercial dos projetos de origem.

## Apresentação do perfil

O arquivo `perfil/README.md` pode ser usado como README do perfil. Para isso, o GitHub usa um repositório público com o mesmo nome de usuário da conta, contendo esse texto como `README.md` na raiz. Preserve conteúdo existente antes de substituí-lo.
