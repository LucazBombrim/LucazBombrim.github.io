# MinerMais — site institucional

**Tipo:** projeto de presença digital e catálogo de nutrição animal.

Demonstração preparada; publicação das imagens pendente.

## Necessidade

Apresentar o negócio, suas linhas e os produtos de forma organizada para quem busca informações sobre nutrição animal.

## Elementos do projeto

- Apresentação institucional da MinerMais.
- Navegação por linhas para bovinos de corte, bovinos de leite, equinos e ovinos.
- Catálogo com identificação e descrição dos produtos.
- Acesso a fichas técnicas em PDF.

## Aprendizado

Traduzir informações de um negócio em conteúdo digital, organizar a navegação de um catálogo e facilitar a localização de informações por linha de produto.

## Escopo deste portfólio

O repositório contém o estudo de caso; a demonstração está preparada para publicação. A versão é identificada como demonstração educacional, sem operação de vendas. A miniatura do portfólio é ilustrativa.
