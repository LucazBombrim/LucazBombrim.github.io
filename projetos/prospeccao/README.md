# Mapa de oportunidades comerciais

**Projeto:** Mapa MinerMais — Prospecção Agropecuária · **Tipo:** aplicação web e estudo de caso.

[Abrir demonstração](https://lucazbombrim.github.io/prospeccao/)

## Necessidade

Organizar a prospecção de criadores e agropecuárias a partir de Itaporanga, SP. A busca por novos clientes exige reunir localização, contatos e informações úteis para as próximas abordagens.

## Proposta do projeto

Um mapa de prospecção com filtros, consulta de contatos e acompanhamento comercial. A experiência conecta informações de potenciais clientes à organização da rotina de vendas.

## Elementos do projeto

- Mapa de oportunidades do setor agropecuário.
- Filtros para explorar as informações.
- Contatos reunidos para consulta.
- Acompanhamento das atividades comerciais.

## Aprendizado

Transformar uma necessidade comercial em uma estrutura digital, organizar dados de prospecção e pensar na consulta das informações durante o trabalho.

## Escopo deste portfólio

Este repositório apresenta o estudo de caso e os arquivos da demonstração em `prospeccao/`, na raiz. A versão pública usa 14 cadastros inteiramente fictícios. A aplicação de origem e sua base de contatos permanecem restritas. A miniatura do portfólio é ilustrativa.

Não há métricas verificadas de conversão, contratos ou receita atribuídas ao projeto.
