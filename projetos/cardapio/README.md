# Lollo Cake — cardápio digital

**Tipo:** projeto web de catálogo e organização de pedidos.

[Abrir demonstração pública](https://lucazbombrim.github.io/cardapio/)

## Necessidade

Apresentar os produtos com mais clareza e facilitar o caminho entre escolher os itens e conversar com o atendimento.

## Elementos do projeto

- Produtos com imagens maiores, categorias e busca.
- Botão de adicionar produtos ao pedido.
- Carrinho com os itens selecionados.
- Montagem da mensagem do pedido para abrir no WhatsApp.
- Informações do estabelecimento e navegação pelo catálogo.

## Fluxo de uso

O cliente encontra os produtos, adiciona os itens ao carrinho e abre o WhatsApp com a mensagem preparada. A mensagem é enviada pelo próprio cliente. A funcionalidade não equivale a confirmação de compra, pagamento ou disponibilidade.

## Aprendizado

Organização de catálogo, clareza de apresentação dos produtos e construção de um fluxo que conecta seleção de itens ao atendimento comercial.

## Escopo deste portfólio

O repositório contém a demonstração e este estudo de caso. A versão pública preserva o catálogo e o carrinho, mas exibe uma prévia da mensagem em uma janela local, sem abrir o WhatsApp nem enviar pedidos ao estabelecimento. Os valores são ilustrativos para este contexto. A miniatura do portfólio é ilustrativa.

A demonstração mantém os 282 produtos e usa ícones e ilustrações no lugar das fotos. O carrinho e a prévia da mensagem continuam disponíveis.
