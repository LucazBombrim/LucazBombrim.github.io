# Atlas — espaço de estudos

**Tipo:** projeto pessoal de organização do aprendizado · **Formato:** aplicação web.

[Abrir demonstração](https://lucazbombrim.github.io/atlas/)

## Necessidade

Organizar materiais, exercícios e rotina de estudo para manter a continuidade do aprendizado. A versão atual do projeto trabalha uma trilha de Dados e BI de 24 semanas.

## Elementos do projeto

- Trilha por semanas e matérias.
- Conteúdos, videoaulas e exercícios.
- Registro de progresso e sessões de estudo.
- Revisão espaçada, caderno de erros e anotações.
- Laboratório SQL e espaço para projetos de aprendizado.
- Backup do progresso registrado no navegador.

## Aprendizado

Estruturação de conteúdo, organização de navegação, acompanhamento de atividades e adaptação de uma experiência digital para uma rotina de estudo pessoal.

## Escopo deste portfólio

O repositório contém o estudo de caso e os arquivos estáticos da demonstração em `atlas/`, na raiz. O progresso é registrado no navegador do visitante. O currículo de estudo inclui Excel, SQL, Power BI e DAX, mas a existência dessa trilha não significa que Lucas já concluiu os conteúdos ou domina essas ferramentas profissionalmente.

A miniatura é uma representação ilustrativa, sem métricas de estudo inventadas.
